# Fix My Code Challenge

Debugging exercises: each task gives a buggy program, and the goal is to find and fix the bug.

| # | Task | File | Fix |
|---|------|------|-----|
| 0 | FizzBuzz | `challenge/0-fizzbuzz.py` | Check multiples of 15 before 3 and 5 |
| 1 | Print square | `challenge/1-print_square.js` | Parse size in base 10, not 16 |
| 2 | Sort | `challenge/2-sort.rb` | Insert at index `i`, not `i - 1` |
| 3 | User password | `challenge/3-user.py` | Store hash in `__password` and compare in lowercase |
| 4 | Double linked list | `challenge/4-delete_dnodeint/` | Relink `prev`/`next` correctly before freeing the node |
